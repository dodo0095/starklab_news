# StarkLab News 使用手冊（本機穩跑）

專案路徑：`C:\Users\AUSER\Desktop\starklab_news`

## 每天怎麼用

### 看資料（開網頁）

```powershell
cd C:\Users\AUSER\Desktop\starklab_news
powershell -ExecutionPolicy Bypass -File scripts\start_server.ps1
```

瀏覽器開啟：**http://localhost:8080/**

- 建議書籤這網址  
- 關掉 PowerShell 視窗 = 關掉網站（本機 server 會停）  
- 不要直接雙擊 `index.html`（JSON 可能讀不到）

### 手動更新資料（不用等排程）

```powershell
cd C:\Users\AUSER\Desktop\starklab_news
powershell -ExecutionPolicy Bypass -File scripts\update_with_log.ps1
```

或：

```powershell
python scripts\run_all.py
```

更新後**重新整理**瀏覽器（Ctrl+F5）即可。

## 自動排程（每天 4 次：04:00 / 08:00 / 14:00 / 20:00）

| 任務名稱 | 時間 | 用途 |
|----------|------|------|
| `StarkLabNews_0400` | 每天 04:00 | 美股收盤後 |
| `StarkLabNews_0800` | 每天 08:00 | 台股開盤前 |
| `StarkLabNews_1400` | 每天 14:00 | 台股收盤後 |
| `StarkLabNews_2000` | 每天 20:00 | 美股開盤前 |

> 每次都會執行 `run_all.py`，重抓全部真實資料（市場 / 新聞 / TSMC / 本益比 / 事件 / Fed）並覆蓋舊檔。單一腳本失敗只保留該項上次成功資料，不影響其他。

### 一次設定

```powershell
cd C:\Users\AUSER\Desktop\starklab_news
powershell -ExecutionPolicy Bypass -File scripts\register_tasks.ps1
```

### 確認有掛上

```powershell
schtasks /Query /TN StarkLabNews_0400
schtasks /Query /TN StarkLabNews_0800
schtasks /Query /TN StarkLabNews_1400
schtasks /Query /TN StarkLabNews_2000
```

### 看日誌（排程有沒有真的跑）

日誌在：

```
C:\Users\AUSER\Desktop\starklab_news\logs\update-YYYY-MM-DD.log
```

例如今天：`logs\update-2026-07-27.log`

成功大致會看到各腳本 `[ok] wrote data\...` 與最後 `exit=0`。

### 電腦當時是關機？

- 排程設了 `StartWhenAvailable`：開機後有機會補跑  
- 最穩仍是：**開機後若錯過時點，手動跑一次** `update_with_log.ps1`

### 取消排程

```powershell
schtasks /Delete /TN StarkLabNews_0400 /F
schtasks /Delete /TN StarkLabNews_0800 /F
schtasks /Delete /TN StarkLabNews_1400 /F
schtasks /Delete /TN StarkLabNews_2000 /F
```

## 頁面上的狀態怎麼看

| 畫面 | 意思 |
|------|------|
| 右上角「資料就緒」 | 最近有成功更新的 JSON |
| 「資料可能過期」 | 超過約 36 小時沒更新成功 |
| 區塊「資料更新中」 | 該 JSON 空或缺資料 |
| 紅色錯誤框 | 該區塊 JSON 讀取失敗 |

排程失敗時**不會清掉**舊 JSON，頁面仍顯示上一次成功資料。

## 常見問題

**Q：排程顯示成功，但資料沒變？**  
A：看 `logs\update-*.log` 是否有網路錯誤或 yfinance 失敗。可手動跑 `update_with_log.ps1` 對照。

**Q：換電腦 / 搬資料夾？**  
A：到新路徑重新執行 `register_tasks.ps1`（任務會綁當下路徑）。

**Q：只想換河流圖股票？**  
```powershell
$env:STOCK_SYMBOL = "2317.TW"
$env:STOCK_NAME = "鴻海"
python scripts\fetch_stock_ma.py
```

**Q：網頁打不開？**  
A：先確認 `start_server.ps1` 還在跑；埠被占用可換：  
`powershell -File scripts\start_server.ps1 -Port 8081`

## 建議使用節奏（2～3 個交易日驗收）

1. **Day 0**：設排程 + 手動更新一次 + 開站看一眼  
2. **隔日 08:10**：看 `logs` 是否有今天檔案、網頁時間是否更新  
3. **當日 20:10**：再確認一次 20:00 任務  
4. 連續正常 → 本機穩跑達標；之後再考慮上伺服器或加功能
