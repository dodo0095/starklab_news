# 金十資料源技術驗證結論

> 驗證日期：2026-07-27  
> 狀態：**MVP 降級為 P1，主線改用備援源**

## 驗證結果摘要

| 檢查項 | 結果 |
|---|---|
| 公開免費 API | **無**（需申請 [open.jin10.com](https://open.jin10.com/) secret-key） |
| 官方 RSS | **未見穩定公開 RSS**；社群多改走 RSSHub 等第三方 |
| 免費引用頁 / iframe | **已於 2025-12-01 停止服務** |
| 爬網頁 | 站點高度前端渲染，且有使用條款；不適合一週 MVP 硬爬 |
| 對應本專案 JSON schema | 理論上可行，但需付費/申請 API，風險與時程不符 |

## 決策（對應 MVP 第六節）

- **報價 / 均線 / ADR** → `yfinance`（穩定、免費）
- **重大新聞前五大** → Yahoo Finance RSS / 公開財經 RSS
- **非農等經濟事件** → 腳本維護 `events.json`（可手填或後續接行事曆 API）
- **金十** → 列為 **P1**：有 API Key 後再接 `open-data-api.jin10.com`

## 若日後要接金十

1. 至 [open.jin10.com](https://open.jin10.com/) 申請 secret-key  
2. 快訊端點範例（需認證）：`https://open-data-api.jin10.com/data-api/flash`  
3. 在 `scripts/fetch_news.py` 增加 `source=jin10` 分支，輸出仍寫入 `data/news.json`  
4. 畫面**不需修改**（只讀 JSON）
