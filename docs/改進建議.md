## 二、⭐ 重點功能：消息面熱度指針（市場情緒溫度計）

### 2.1 它到底量什麼（先定義清楚，避免做出模糊的東西）

「熱 / 冷」建議定義為 **市場情緒溫度計**，把多個訊號合成一個 **0–100 分**：

| 訊號 | 來源（皆為現有資料） | 對熱度的影響 |
|---|---|---|
| 新聞情緒 | 前五大 + TSMC 新聞，用**中文利多/利空詞典**打分（創高/樂觀/大漲 vs 重挫/警告/恐慌） | 利多多 → 熱 |
| 消息量 / 重大度 | `news.json` 中「重大」標籤數量 vs 平常基準 | 量大 → 熱 |
| 聯準會傾向 | `fed.json` 已算的 鷹 / 鴿 | 鴿 → 偏熱、鷹 → 偏冷 |
| 大盤動能 | `market.json` 今日漲跌幅 | 漲 → 熱 |

加權合成 → 0–100 分 → 五段：**冰冷 / 偏冷 / 中性 / 偏熱 / 過熱**。

### 2.2 為什麼有價值

- **「過熱」是反指警訊**：消息一面倒樂觀時，往往是相對高點。
- 這與本益比河流圖的「**5 年高點**」互相呼應——**兩個訊號同時亮 = 很強的「該謹慎」提示**，正是「安心丸」體驗的升級。

### 2.3 怎麼做（完全符合現有架構）

1. 新增 `scripts/fetch_heat.py` → 產生 `data/heat.json`：
   ```json
   {
     "score": 68,
     "level": "偏熱",
     "updated_at": "2026-07-28T08:00:00+08:00",
     "components": { "sentiment": 0.6, "volume": 0.7, "fed": 0.3, "market": 0.4 },
     "drivers": ["利多新聞偏多", "Fed 偏鴿", "台股今日上漲"]
   }
   ```
2. 前端用 **ECharts 儀表（gauge）**：半圓指針、藍(冷)→紅(熱)漸層弧、中央大字「偏熱 68」、下方列出 2–3 個「為什麼熱」的驅動因子。
3. 版面位置：**市場總覽那一排旁邊**或 hero 上方，開盤前第一眼就看到。

### 2.4 誠實的限制（務必標註）

- 關鍵字情緒分析是**粗略**的，畫面須標「**參考情緒指標，非投資建議**」。
- 這是加分訊號，不是聖杯；與其他資訊交叉看才有意義。

### 2.5 兩種可選定義（開發前二選一）

- **A（建議）市場情緒溫度計**：合成 情緒 + 量 + Fed + 大盤，一根指針 0–100。
- **B 單純新聞熱度**：只看消息量與利多利空，較單純但資訊量較少。

## 三、UI 改進（依 CP 值排序）

| 優先 | 改進 | 為什麼 | 工作量 |
|---|---|---|---|
| 🟢 高 | **河流圖旁加「怎麼看」說明**（如參考站「目前位於 5 年高點，代表…」） | 使用者才懂紅色到頂 = 可能高估，直接兌現「安心丸」 | 低 |
| 🟢 高 | **「5 年高點」徽章放大成醒目色塊** | 最重要的結論目前藏在工具列，不夠搶眼 | 低 |
| 🟢 高 | **每格顯示自己的更新時間 +「N 小時前」** | 金融資料，使用者要知道新不新 | 低 |
| 🟡 中 | **載入用骨架動畫取代虛線框** | 目前空狀態較陽春 | 中 |
| 🟡 中 | **新聞加來源標籤 / 相對時間、去重** | 中文 RSS 偶爾重複、有雜訊 | 中 |
| 🟡 中 | **手機版確定 hero（河流圖）排最前** | 手機是主要使用場景 | 低 |
| ⚪ 低 | **深色模式**（目前僅淺色） | 加分、非必要 | 中 |

## 四、產品 / 資料層改進（比 UI 更深的價值）

1. **股票代碼查詢「玩真的」**：目前輸入框只提示要跑後端。可**預先產生觀察名單**（2330 / 2317 / 2454…）的 `valuation_{代碼}.json`，輸入即可切換——把 P1「個人股票走勢查詢」真正做出來。
2. **新聞加一句中文摘要**（TSMC / Fed 目前僅標題）——最能提升「省時間」的感受。
3. **淨值比（PB）河流圖**把切換補完（目前點 PB 顯示「稍後開放」）。
4. **訊號聯動提示**：當「河流圖 5 年高點」+「情緒過熱」同時出現 → 頂部給一條醒目提醒。

## 五、建議的執行順序

| 順序 | 項目 | 理由 |
|---|---|---|
| 1 | **消息面熱度指針（方案 A）** | 價值最高、用現有資料、與河流圖形成雙訊號 |
| 2 | UI 高 CP 值三項（怎麼看說明 / 醒目徽章 / 各格更新時間） | 低工、直接提升「看得懂」 |
| 3 | 新聞中文摘要 + 去重 | 兌現「省時間」核心價值 |
| 4 | 股票代碼查詢玩真的（觀察名單） | 把 P1 個人化查詢落地 |
| 5 | PB 河流圖、深色模式、訊號聯動提示 | 行有餘力的加分項 |

## 六、風險與原則提醒

- **不構成投資建議**：情緒指標、估值帶皆為資訊參考，畫面須明示免責。
- **假資料防呆**：示範資料一律標紅「非真實股價」，抓取失敗不得無聲顯示舊/假值。
- **範圍紀律**：一次做一項、先求穩定可 Demo，再往下擴充。
