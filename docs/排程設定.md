1# Windows 工作排程器設定

目標：每天 **4 個時段**自動執行全站資料更新（重抓真實資料並覆蓋）：
**04:00**（美股收盤後）、**08:00**（台股開盤前）、**14:00**（台股收盤後）、**20:00**（美股開盤前）。

## 前置

1. 已安裝 Python 3.10+
2. 在**本專案根目錄**（含 `index.html`、`scripts/` 的那一層）執行過：

```powershell
cd <本專案根目錄>
pip install -r requirements.txt
python scripts\run_all.py
```

`<本專案根目錄>` 請換成你 clone / 開啟此 repo 的實際路徑，不要寫死機器上的工具目錄。

## 方式 A：一鍵建立排程（建議）

以**系統管理員**開啟 PowerShell，執行：

```powershell
cd <你的專案路徑>
powershell -ExecutionPolicy Bypass -File scripts\register_tasks.ps1
```

會建立四個工作（並自動清掉舊版 21:00 排程）：

- `StarkLabNews_0400`（04:00）
- `StarkLabNews_0800`（08:00）
- `StarkLabNews_1400`（14:00）
- `StarkLabNews_2000`（20:00）

## 方式 B：手動建立

1. 開啟「工作排程器」→ 建立基本工作  
2. 名稱：`StarkLabNews_0400`  
3. 觸發程序：每天 04:00  
4. 動作：啟動程式  
   - 程式：`python`（或本機 `python.exe` 的完整路徑）  
   - 引數：`scripts\run_all.py`  
   - 起始於：**本專案根目錄**
5. 再複製三份，分別改為 `StarkLabNews_0800`(08:00)、`StarkLabNews_1400`(14:00)、`StarkLabNews_2000`(20:00)

## 驗證

```powershell
# 立刻手動跑一次
python scripts\run_all.py

# 看任務是否存在
schtasks /Query /TN StarkLabNews_0400
schtasks /Query /TN StarkLabNews_0800
schtasks /Query /TN StarkLabNews_1400
schtasks /Query /TN StarkLabNews_2000
```

## 失敗容錯

- 單一腳本失敗**不會覆寫**既有 JSON（失敗時直接 return，不寫檔）  
- 網頁會讀「上一次成功的 JSON」，並在資料過舊時顯示黃色提示  
- 日誌：可在排程動作加上 `>> logs\update.log 2>&1` 自行記錄

## 靜態站開啟方式

```powershell
cd <專案路徑>
python -m http.server 8080
```

瀏覽器開啟：http://localhost:8080/
