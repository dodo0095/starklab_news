## 五、版面重新規劃（UI）

**現況問題**：所有區塊由上到下擠成單欄一長條，新聞又全混在一份清單裡 → 視覺很亂、抓不到重點。

**新版面原則**：把每個需求拆成**獨立格子**，依「開盤前閱讀順序」由上而下：

```
┌─ 市場總覽（4 格 KPI）：道瓊 / 納斯達克 / S&P500 / 台積電 ADR ──────┐  P0
├─ 估值河流圖（主角，佔 2/3 寬）┆ 側欄：非農事件 + 大盤支撐簡版 ──┤  核心 + P0/P1
│   含股票代碼輸入框、PE/PB 切換、目前落點標籤                        │
├─ 美國重大新聞前五大 ┆ TSMC 專區 ┆ 聯準會發言 ───────────────────┤  P0/P0/P1
├─ 全球經濟局勢摘要（寬）        ┆ 價值主張/驗收鉤子 ──────────────┤  P1
└──────────────────────────────────────────────────────────────┘
手機：所有格子自動收合成單欄
```

- 沿用學生現有配色（沉穩藍 + 台股紅漲綠跌），支援亮/暗色。
- **視覺化版面圖**（可直接給學生照做）：見 `docs/ui-layout-mockup.html`，
  線上預覽：https://claude.ai/code/artifact/b3ffa90c-1705-4dcf-b35e-95d2132b39e1
- 重點改動：①新聞不再一坨，拆成「重大新聞 / TSMC / 聯準會」三格；
  ②估值河流圖升為版面主角並加輸入框；③KPI 四格並排取代長條。
