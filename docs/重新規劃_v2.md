## 一、為什麼初版「怪怪的」（根因）

工程品質沒問題，**是「範圍與主角」對錯了對象**。手上三份文件互相矛盾：

| 文件 | 說的核心 | 學生照哪份做 |
|---|---|---|
| `MVP需求規劃.md`（07-26，較舊） | 大而全的資訊整合看板 | ✅ 就是照這份 |
| `MVP規格卡_產品A`（工作坊 Day 2，**最新最權威**） | **一週只做一個核心：河流圖** | ⚠️ 沒對齊 |

三個具體落差：

1. **範圍稀釋**：規格卡要「只做一個核心」，學生做成大盤＋ADR＋五大新聞＋事件＋圖的
   泛用看板。主角被淹沒，看起來抓不到重點。
2. **主角圖種類錯**：規格卡 Must-have 是 **本益比／淨值比 河流圖（估值帶）**，
   學生做的是 **MA5/MA20/MA60 均線河流圖**。兩種是完全不同的圖，方向錯了。
3. **規格卡自身矛盾**：同張卡 Must-have 寫「本益比/淨值比」，範圍紀律欄卻寫「RSI」。
   本益比／均線／RSI 三種圖在文件裡打架 —— 這就是「亂」的來源。
4. **驗收標準空洞**：「每天有安心丸的效果」無法檢查，等於沒有終點線。

## 三、修正後的 MVP 規格（可檢查版）

### 產品一句話
> 開盤前一眼看懂「大盤氛圍＋當日重點新聞」，並用**估值河流圖**判斷手上/關注的個股
> **現在貴不貴** —— 不用自己算、不用自己盯。

### 功能分層（重排）

| 層級 | 功能 | 狀態 |
|---|---|---|
| ⭐ **核心（唯一主角）** | **本益比／淨值比 河流圖**：單檔股票，歷史股價＋估值區間色帶（便宜～昂貴），標出目前位置 | 🔴 **需重做**（現在是均線版） |
| 🟩 支援外殼 | 市場總覽卡片（大盤／台積電 ADR） | ✅ 學生已完成，保留 |
| 🟩 支援外殼 | 重大新聞前五大 | ✅ 學生已完成，保留 |
| 🟨 加分 | 非農等條件事件 | ✅ 已完成，保留 |
| 🟦 P1（本週不做） | 均線河流圖（現有的可留成「切換模式」之一）、RSI 圖、推播、多檔比較 | 延後 |

> 版面調整：把**估值河流圖放到頁面最上方/最顯眼位置**，市場總覽與新聞退為輔助，
> 讓「主角」名副其實。

### 估值河流圖 — 資料與畫法（給學生的技術規格）

- **資料**：yfinance 可取歷史股價；本益比河流圖 = `股價 ÷ 每股盈餘(EPS)` → 得歷史 PE，
  再取 PE 的分位數區間（例如 -1SD / 平均 / +1SD，或 25%/50%/75% 分位）
  **反推回股價空間**畫成色帶：
  - 便宜帶（低 PE 對應的股價）
  - 合理帶
  - 昂貴帶（高 PE 對應的股價）
  - 疊上**實際收盤價線**，一眼看出目前落在哪一帶。
- 淨值比（PB）版同理，把 EPS 換成每股淨值(BPS)。
- **JSON schema 調整**（新的 `data/valuation.json`，取代/並存 `stock_ma.json`）：
  ```json
  {
    "symbol": "2330.TW", "name": "台積電",
    "updated_at": "...",
    "metric": "PE",            // 或 "PB"
    "dates": ["2024-01-01", "..."],
    "close": [900, "..."],
    "bands": {
      "cheap":  [780, "..."],   // 低分位 PE × EPS
      "fair":   [900, "..."],
      "expensive":[1050, "..."]
    },
    "current_pe": 22.5,
    "current_zone": "fair"      // cheap / fair / expensive
  }
  ```
- **前端**：ECharts 用堆疊 area 畫三條帶（技術上和現有均線色帶做法接近，
  學生現有 `renderRiver` 可改造，非從零）。

### 驗收標準（把「安心丸」翻成可檢查條件）

保底（必達）：
- [ ] 網頁可開、手機/電腦皆可看（RWD）—— 已達成
- [ ] 估值河流圖能顯示 **1 檔股票**的歷史股價 + 至少 3 條估值帶（便宜/合理/昂貴）
- [ ] 圖上/圖旁**明確標出「目前落在哪一帶」**（例如標籤：目前 PE 22.5，位於「合理」區）
- [ ] 各區塊有「無資料/更新中」防呆，不白畫面 —— 已達成
- [ ] 市場總覽 + 前五大新聞正常顯示 —— 已達成

加分：
- [ ] 資料由 yfinance 自動產生、08:00/21:00 排程各成功跑過一次 —— 大致已達成
- [ ] 可切換 PE / PB 兩種估值基準

> 「安心丸」= 使用者開盤前打開，30 秒內知道「大盤今天什麼氛圍 + 我關注的股票現在貴不貴」，
> 不用自己算本益比、不用自己盯盤。這就是可以天天用的鉤子。
